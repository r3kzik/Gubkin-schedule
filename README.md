# Расписание (РГУ нефти и газа им. Губкина)

Android-приложение с расписанием группы, по умолчанию **КВ-26-02**.

- Показывает пары по дням: время, предмет, тип занятия, аудиторию, преподавателя.
- Дни листаются свайпом, недели переключаются стрелками; пара, которая идёт сейчас, подсвечена.
- Отменённые и перенесённые пары зачёркнуты.
- Расписание сохраняется в телефоне, поэтому видно и без интернета.
- Каждые 3 часа приложение в фоне проверяет сайт (текущую и следующую неделю). Если что-то
  поменялось (отмена, перенос, другая аудитория или преподаватель, новая пара), приходит уведомление.
- Данные берутся из открытого API расписания `lk.gubkin.ru/schedule`, логин и пароль от ЛК не нужны.
- Если сайт попросит капчу, приложение покажет картинку, и вы введёте код.

## Как получить APK через GitHub (без Android Studio)

1. Зарегистрируйтесь на https://github.com, если ещё нет аккаунта.
2. Нажмите **New repository** (зелёная кнопка или «+» вверху справа).
   Имя, например, `raspisanie`. Лучше сделать **Public**: тогда APK можно скачать на телефоне
   без входа в аккаунт. Галочки README и .gitignore не ставьте. Нажмите **Create repository**.
3. На странице пустого репозитория нажмите ссылку **uploading an existing file**.
   Откройте распакованную папку `GubkinSchedule`, выделите **всё её содержимое**
   (`app`, `gradle`, `.github`, `build.gradle.kts` и остальные файлы) и перетащите в окно браузера.
   Внизу нажмите **Commit changes**.
4. Откройте вкладку **Actions**. Там автоматически запустится сборка «Собрать APK»,
   она идёт около 5–8 минут. Зелёная галочка означает, что всё готово.
5. На главной странице репозитория справа появится раздел **Releases**. Откройте последний релиз
   и скачайте `raspisanie.apk`. Удобнее делать это сразу с телефона.
6. Откройте файл на телефоне. Android попросит разрешить установку из этого источника:
   разрешите и установите.
7. При первом запуске разрешите уведомления. Приложение само найдёт группу КВ-26-02.

### Если вкладка Actions пустая

На macOS Finder скрывает папки, имена которых начинаются с точки, поэтому `.github` могла не загрузиться.
Тогда нажмите **Add file → Create new file**, в поле имени введите `.github/workflows/build.yml`,
вставьте содержимое файла `.github/workflows/build.yml` из архива и нажмите **Commit changes**.

### Если сборка упала (красный крестик)

Откройте упавшую сборку, нажмите на шаг «Сборка» и скопируйте последние строки с ошибкой.
По ним ошибку можно исправить.

## Как обновлять приложение

Любое изменение файлов в репозитории запускает новую сборку и создаёт новый релиз.
Новый APK ставится **поверх** старого: все сборки подписаны одним ключом (`app/raspisanie.keystore`),
поэтому настройки и сохранённое расписание не пропадают.

## Другая группа

Сменить группу можно в самом приложении: меню **⋮ → Сменить группу**.
Группа по умолчанию задаётся в `app/src/main/java/com/vadik/raspisanie/App.kt` (`DEFAULT_GROUP`).

## Через Android Studio (если есть)

Откройте папку проекта в Android Studio (File → Open), дождитесь синхронизации Gradle
и нажмите ▶ Run с подключённым телефоном или выберите **Build → Build APK(s)**.
